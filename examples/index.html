CJNotice.js

Altere os campos e veja a notificação ou o alerta refletirem as configurações em tempo real.

Prévia em execução

A alteração é aplicada enquanto você edita. Use “Exibir agora” para criar uma nova instância.

Área de demonstraçãoAs notificações aparecem nas posições configuradas.

Como usar no seu projeto

Instancie o plugin uma vez e use tasks para avisos rápidos ou confirmações antes de ações importantes.

Task: aviso temporário

Use task() ou métodos como success() para informar o resultado de uma ação. O ID retornado pode ser usado para dispensar a notificação manualmente. 

const notice = new CJNotice({ duration: 4000 });

const taskId = notice.task({
    type: "success",
    position: "top-right",
    icon: "<strong>✓</strong>",
    title: "Tudo certo",
    text: "O arquivo foi enviado.",
});

// Remova antes do tempo, se necessário:
notice.dismiss(taskId, "manual");

Alert: confirmação

Use confirm() ou métodos como confirmWarning() quando a pessoa precisar escolher entre cancelar e confirmar uma ação. 

notice.confirm({
    type: "warning",
    icon: "<strong>!</strong>",
    title: "Excluir arquivo?",
    text: "Esta ação não pode ser desfeita.",
    cancelLabel: "Voltar",
    confirmations: [{
        label: "Excluir",
        onClick: () => excluirArquivo(),
    }],
});
Duração Use duration: 0 para manter uma task até que ela seja fechada ou dispensada.
Posições Tasks aceitam seis posições, como top-right e bottom-center.
Ícones O campo aceita HTML ou SVG confiável. O texto da mensagem continua sendo inserido como texto simples.
