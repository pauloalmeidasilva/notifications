Os recursos essenciais para feedback de interface, sem framework obrigatório e sem camada de configuração escondida.

01

Tasks empilháveis

Mostre vários estados ao mesmo tempo em seis posições, com duração automática ou controle manual.

02

Confirmações claras

Intercepte ações importantes com um alertdialog acessível, foco inicial e suporte à tecla Escape.

03

Tipos semânticos

Use success, error, warning ou info com cores e ícones padrão, mantendo a possibilidade de personalizar cada detalhe.

04

Acessibilidade configurável

Feche tasks com Escape, navegue pelo botão de ação e escolha entre roles status e alert.

05

Movimento sob controle

Escolha slide, fade ou none. A preferência de movimento reduzido desativa todas as transições.

06

Sem acoplamento

Funciona com JavaScript vanilla e pode ser usado em qualquer aplicação que aceite módulos ES.

Comece em poucos passos.

Instale o pacote, carregue os estilos e crie uma única instância para reutilizar na aplicação. 

npm install cj-notice

import CJNotice from "cj-notice";
import "cj-notice/style.css";

const notice = new CJNotice({ duration: 4000 });
notice.task({
    title: "Tudo certo",
    text: "O arquivo foi enviado.",
});
Uma instância, vários fluxos.
Use task() para feedback imediato e confirm() antes de operações que exigem decisão. O método show() continua disponível como sinônimo explícito de task.

API de implementação

Os métodos públicos foram desenhados para serem previsíveis tanto em uma tela simples quanto em um fluxo complexo.

new CJNotice(options)

Cria uma instância. Aceita defaults como duration, position, cores, borda, raio e onConfirmClose.

configure(options)

Atualiza os defaults da instância e retorna o próprio objeto para encadeamento.

show(options)

Exibe uma task e retorna seu ID. Use title, text, icon, type, position, duration, estilos, onClose e onExpire. O role pode ser status ou alert, e animation aceita slide, fade ou none. Também aceita pauseOnHover, progress, maxVisible, stackOrder e content.

update(id, options)

Atualiza uma task sem removê-la. Tasks acima de maxVisible aguardam em fila por posição e são exibidas quando houver espaço.

task(options)

Atalho semântico para show(options), ideal para comunicar tarefas ou estados rápidos.

success() · error() · warning() · info()

Métodos convenientes para criar tasks com presets semânticos de cores e ícones.

dismiss(id, reason)

Remove a task informada. O motivo padrão é dismiss; você pode usar motivos próprios, como manual.

confirm(options)

Abre um alertdialog. Configure type, cancelLabel, onCancel e a lista confirmations com label e onClick.

confirmSuccess() · confirmError() · confirmWarning() · confirmInfo()

Métodos convenientes para confirmações com presets semânticos.

Detalhes que evitam surpresas.

Algumas decisões da API são intencionais e ajudam a manter o uso seguro.

Ícones SVG e HTML.
O campo icon é inserido como HTML. Use apenas conteúdo confiável, como SVGs do próprio projeto. O título e o texto da notificação são tratados como texto simples. 
const taskId = notice.task({
    position: "bottom-right",
    duration: 0,
    icon: '<svg aria-hidden="true" ...>...</svg>',
    title: "Processando",
    text: "Aguarde a conclusão.",
    onClose: ({ reason }) => console.log(reason),
});

// Quando terminar:
notice.dismiss(taskId, "completed");
